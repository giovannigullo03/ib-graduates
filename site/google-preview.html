This preview needs your own Google Maps API key

A key can only be created from a Google Cloud account with billing enabled, so it has to come from you — paste it below and the map loads immediately. It is kept in this browser only (localStorage), never sent anywhere else and never committed.

  1. Open console.cloud.google.com → create or pick a project.
  2. Enable Maps JavaScript API (that is the only one this page uses).
  3. APIs & Services → Credentials → Create credentials → API key.
  4. Restrict it to HTTP referrers localhost:* and your Pages domain, so a leaked key is useless elsewhere.
What changes if you adopt this. The current map costs nothing: Leaflet is open source and the Esri basemap is free without a key. Google's Maps JavaScript API bills per map load. There is a monthly free allowance that a personal project stays inside easily, but a public site that gets shared widely can start accruing charges, and the key sits in client-side code where anyone can read it — referrer restrictions are what stop it being abused.

The upside is not the basemap. It is that adopting Google removes the terms-of-service obstacle to using Google Places for the 308 career stops that carry only a company name and no city — the ones neither OpenStreetMap nor ROR can find.
